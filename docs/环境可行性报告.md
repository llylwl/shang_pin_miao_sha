## 三、Redis 缺失的处理方案（任选其一）

### 方案 A：不装 Redis，直接跑（推荐先这样）

应用定位就是「Redis 可降级」：

```bash
java -jar target/shang_pin_miao_sha.jar
```

- 商品详情：读 DB → 本地缓存，功能可用；
- 秒杀扣库存：返回 `503 当前为降级模式`（不会超卖，也不会报 500）；
- 热 Key 监控、演示数据、健康检查：全部正常。

### 方案 B：用便携版 Redis 跑全功能（本次已验证）

本次验证用的是 `redis-windows` 的 Windows 便携版，放在 `C:\Users\Administrator\.dsh\ungrouped\_redis`：

```bash
# 1. 启动 Redis（6379 被系统占用，这里用 16379）
cd C:\Users\Administrator\.dsh\ungrouped\_redis\Redis-8.10.3-Windows-x64-msys2
.\redis-server.exe --port 16379 --bind 127.0.0.1 --save "" --appendonly no

# 2. 启动应用并指向该端口
java -jar target/shang_pin_miao_sha.jar --spring.data.redis.port=16379
```

也可以安装为 Windows 服务（发行包中带 `with-Service` 版本），或改用 [Memurai](https://www.memurai.com/)。

### 方案 C：WSL / Docker

```bash
# WSL（若已启用）
wsl -d Ubuntu -- redis-server --port 16379 &

# Docker（若已安装）
docker run -d --name redis -p 16380:6379 redis:7-alpine
```

然后 `--spring.data.redis.port=16380`。

## 四、注意事项

1. **端口**：8080 若被占用，用 `--server.port=18080`（本次验证用的就是 18080）。
2. **中文乱码**：Windows 控制台默认 GBK，启动时加 `-Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8`。
3. **MySQL 账号**：默认 `root/root`，如不同请用 `--spring.datasource.password=xxx` 覆盖。
4. **重复导入数据**：`db/schema.sql` 与 `db/data.sql` 都是幂等的；若想彻底重置，执行
   `DROP DATABASE shang_pin_miao_sha;` 后重新执行 `db/init.sql`。
5. **数据库集成测试**：默认跳过（避免无数据库环境构建失败），需要时设置 `RUN_DB_TEST=true`。
